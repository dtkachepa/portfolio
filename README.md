# DTK Portfolio

Personal portfolio for Dickson Tinashe Kachepa, built with Next.js, React,
TypeScript, Tailwind CSS, and Framer Motion.

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm run build
```

## Deployment

Push the `main` branch to GitHub and import the repository into Vercel. Vercel
will detect the Next.js configuration automatically.
